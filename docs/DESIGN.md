# 画面の決めごと（オーナー画面・ゲスト画面共通）

デザイン基準 §1.5（アプリ・業務画面）に沿う。見た目より「迷わない・数字が読める」を優先する。

## 目的（1文）
民泊のオーナーが、チームの下書きとプログラムが数えた数字を確かめて、**OK・直す・コピー**だけで事務を終える画面。

## 言葉（同じものは同じ言葉で）
| 使う言葉 | 使わない言葉 | 意味 |
|---|---|---|
| 下書き | 送信文・回答 | AIが書いた文。まだ誰にも届いていない |
| 確認済み | 承認・確定 | オーナーが「OK」を押した下書き |
| コピー済み | 送信済み | コピーした。送るのはオーナー本人 |
| 集計表 | 申告書・納付書 | 宿泊税・定期報告の数字の表 |
| 予約 | 案件・ブッキング | 1件の泊まり |
| ゲスト | 宿泊者様・客 | 泊まる人 |
| 人泊 | 延べ人数（宿泊税では） | 人数×泊数 |
| 預かった額 | 徴収額 | 予約サイト・宿が預かった宿泊税 |
| 使った日・予約済みの日・残り | 稼働日 | 180日の数え方 |
| チーム／担当 | AI・ボット | 番頭・経理担当・監査役・宿泊担当・経営企画 |

ボタンの言葉は「OK」「直す」「コピー」「つくる」に限る。「送信」「提出」「申告」は置かない。
画面の行き来と取り消しの「開く」「やめる」「CSVを保存」は可（外へ何も出さないため）。

## 形・間隔・文字
- 角丸は **10px の1種類**（小さな札だけ 999px）
- 間隔は 4／8／12／16／24 の段だけ
- 書体：**BIZ UDPGothic**（400／700）1書体。理由＝オーナーは年配の方も多く、数字の読み違い（3と8、1と7）を減らしたい。宿泊税・日数の数字が主役の画面なので UD 書体を選ぶ。数字は等幅（tabular-nums）
- 文字の大きさは下の「年配の方にも読みやすく」の表が正（旧：本文 16px・数字の主役 32px）。行間 1.8
- 罫線を何本も引く「新聞風」にしない。区切りはカードと余白で作る。番号を振った見出しにしない

## 年配の方・ITが苦手な方にも使いやすく（2026-11-03 追加・見本 `design/sample.html` で社長が方向OK）

### ねらい（1文）
スマホに慣れていない60代のオーナーでも、**説明なしで「どこを押せばいいか」が分かり、数字を読み違えない**画面にする。

### 文字の大きさ（スマホ幅で）
| 使う場所 | 大きさ | 太さ |
|---|---|---|
| 本文・ボタンの文字 | 18px | 400／ボタン 700 |
| 補足（「見込み」「〇月より」など） | 16px | 400 |
| いちばん小さい注意書き（画面の下の3行） | 15px | 400。これより小さくしない |
| 画面の見出し | 22px | 700 |
| 数字の主役（1画面に1つ） | 40px | 700 |
| 2番目の数字 | 28px | 700 |

数字は等幅（tabular-nums）・右そろえ・3けた区切り。「円」「%」は数字より小さく（数字の 0.5倍）。

### 押すところ
- 押せるものは **高さ 56px 以上**・文字つき（アイコンだけのボタンは置かない）
- 濃い色の塗りボタンは **1画面に1つ**。ほかは白地に枠線
- 押せないもの（札・チームの名前）は、**ボタンに見える形にしない**（枠の丸い札・影・指のカーソルを使わない）
- 長押し・横すべり（スワイプ）・横スクロールなど、**見えない操作は使わない**

### 画面の行き来（タブをやめて「ホーム」に）
- 横に並んだタブは、スマホで端が切れて見えないものが出るのでやめる
- 最初の画面は **ホーム**。6つの仕事を**1列の大きな行**で並べる（左にしるし・名前・その仕事のいまの数字1行・右に「›」）。WESTER の一覧の作り方を借りる
- 行に出す数字はプログラムが数えたものだけ。数えていないもの（件数など）は説明の言葉にして、数を作らない
- 各画面のいちばん上に、いつも **「← ホームへ戻る」**（高さ 56px）

### チームの帯（Signature はそのまま・形を変える）
- 丸い札（ボタンに見える）をやめ、**名札**にする：担当名＋いまの様子（「待っています」「数えています」）
- 働いている担当だけ --glow の左の太線と明るい地で光る。色だけでなく「いま働いています」の言葉も出す

### 数字の見せ方（マネーフォワード家計簿の「数字とグラフ」を借りる）
- 上に **数字の主役を1つ**。見込みではなく**決まっている数字**を主役にする（今月の数字なら「売上」）
- 今月の数字は **カードを2枚に分ける**（2026-11-03 社長案）
  - 1枚目「〇月の売上」：売上（40px）＋前の月との差＋泊まり済み／これからの横棒＋「宿泊税は預かったお金なので売上に入れていない」
  - 2枚目「手元に残るお金（見込み）」：売上・キャンセル料・予約サイトの手数料（−）・手取り（28px）のレシート。1枚目のすぐ下に置き、売上を手取りと思い込ませない
- ホームの「今月の数字」の行は「〇月の売上 〇円」を出す
- **レシートのような明細**：左に言葉、右に金額。引く金額は「−」を付ける。最後の行は太字で区切る
- 内訳は **ドーナツの図＋表**。図の色だけで分からないよう、表に名前・金額・%を必ず書く
- 「泊まり済み／これから」は **2つに分けた横棒**＋それぞれの金額
- 前の月との差は「9月より +28,000円」と **言葉で**書く（↑↓の矢印や色だけにしない）
- 見込みの数字には必ず「見込み」と書く

### やらないこと（追加）
- 横スクロール・長押し・スワイプ
- 色だけで意味を伝える（必ず言葉を添える）
- 15px より小さい文字
- 押せないものをボタンの形にする
- 数えていない数字を飾りとして出す（「新着3件」のような作った数）

## 状態（すべての画面で用意する）
- 空：「まだありません」＋次にやること1つ
- 読み込み中：何を待っているかを書く（「経理担当が数えています」ではなく、数えるのはプログラムなので「プログラムが数えています」）
- エラー：何が起きたか＋どうすればいいか。中身（文や番号）は出さない
- 完了：何が終わったか＋次にやること

## いつも出すもの（画面の下）
- 下書きです。確認と提出・送信はご本人が行います
- デモのデータはすべて架空です
- AIの処理は米国のAnthropic社で行います

## 安全のための約束（画面側）
- AI・ゲスト由来の文は必ず textContent で出す（innerHTML を使わない）
- 画面の中に `<script>` や `style=""` を書かない（CSP で止めている）
- 暗証番号は画面に出さない。コピーのときだけクリップボードに入る
- CSV の書き出しは `=` `+` `-` `@` で始まる文字の前に `'` を付ける
