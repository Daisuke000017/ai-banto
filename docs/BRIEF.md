# BRIEF.md — AI番頭 オーナー画面（ハッカソン「Built with Claude: Japan 2026」）
更新日：2026-11-03／書いた人：ハンコック（仕様書 v1.4 §0〜§1・§6・§10 をもとに。聞き取り相手＝社長）
対象：オーナー画面の3タブ（宿泊税・民泊の手続き・ゲスト連絡）。ゲスト画面はまだ無いので対象外。

## 1. 目的（この画面で起きてほしい変化を1つ）
1人で民泊を営むオーナーが、月末の事務（宿泊税の集計・180日の残り・定期報告・ゲストへの案内）を、**数字と下書きを確かめて「OK」「コピー」を押すだけ**で終えられると感じる。
あわせて、3分動画を見た審査員が「AIは文を書き、数はプログラムが数え、送るのは本人」という分担を一目で理解する。

## 2. 相手（誰が・どんな状況で・何を気にして見るか）
- **主な相手**：宮崎・青島近くで、親の家の空いた2部屋を家主居住型の民泊で貸す30代（東京から子育てで戻った人・架空）。宿名「しおさいの家」。予約は Airbnb・Booking.com・楽天。ゲストは韓国・台湾・香港・欧州。家事と仕事の合間に、スマホか家のパソコンで開く
- **同じくらい大事な相手**（2026-11-03 追加）：親の代から家を貸している60代のオーナー（架空）。スマホは LINE と電話くらい。老眼で小さい文字は読みにくい。「どこを押せばいいか分からない」「押したら取り消せないのでは」が怖い。→ 文字の大きさ・押すところ・ホーム画面は `docs/DESIGN.md`「年配の方・ITが苦手な方にも使いやすく」に従う
- **もう1つの相手**：3分動画を見るハッカソンの審査員（デモ 25%・Claude の使い方 25%）。動画はPCのブラウザをスマホ幅で撮る
- **いちばん気にしていること**：法律の数字（年180日・2か月ごとの報告・宿泊税 1人1泊200円）を**間違えたくない**。外国語の案内で**金額・日付が正しく伝わっているか**分からない
- **すでに持っている不安・誤解**：「AIに任せると勝手に送られる・数字をでっち上げる」。「税務ソフトや予約管理システム（PMS）を新しく覚えないといけない」

## 3. してほしい行動（1つだけ）
- **主**：プログラムが数えた数字・チームの下書きを見て、**「OK」または「コピー」を押す**（各タブで濃い色のボタンは1つ）
- **副**：「直す」（金額や文を手で直す）、内訳を「開く」、「CSVを保存」

## 4. 約束（言い切れること・根拠つき）
| 約束 | 根拠 |
|---|---|
| 税額・日数はAIではなく決まった式で数える | 宿泊税・180日・定期報告はプログラムの計算。テスト50件が通っている |
| 勝手に送らない・提出しない | 画面に「送信」「提出」ボタンが無い。コピーして本人が予約サイトに貼る |
| 訳した文の金額・日付をもう一度確かめる | 訳し戻しと検査（数字・日付の照合）、監査役の確認を画面に出している |
| ドアの暗証番号はAIに渡さない・画面に出さない | 伏せた箇所を紫の札で示し、コピーのときだけ差し込む |

## 5. 競合との違い
- **同業がみな言っていること**（言っても差にならない）：「AIで業務効率化」「チャットで何でも聞ける」「ダッシュボードで見える化」
- **この画面だけが言えること**：ホテルの裏方（経理・監査・宿泊・企画）を**チームの担当として見せ、いま誰が働いているかが光る**。そして**AIが書いたもの／プログラムが数えたもの／本人が押すもの**が画面の上で分かれている。チャット欄が無い
- **Signature（記憶される要素）**：上の帯の「チーム」（番頭・経理担当・監査役・宿泊担当・経営企画）が、働いている担当だけ光る。下書きの中の伏せた暗証番号が紫の札で見える
