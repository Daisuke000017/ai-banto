# AI番頭（ai-banto）

宮崎の小さな民泊オーナーのための「裏方の事務」をAIが手伝うアプリ。
Built with Claude: Japan 2026 ハッカソン（2026-11-02〜11-08）で開発中。

## つくるもの（予定）
- 予約台帳から、180日の上限・2か月ごとの定期報告・宿泊税の数字を自動で数える
- 予約サイトの入金と予約の突き合わせ（月末の締め）
- 海外ゲストへの案内文の下書き（多言語）

## 構成
- Cloudflare Workers（画面・API）／Cloudflare D1（データベース）
- Anthropic API（Claude）

## データについて
このリポジトリのデータはすべて**架空のもの**です。実在のお客様・宿泊者の情報は含みません。
